
## Part 9: Critical Questions for Instructor Feedback

### Theoretical Framework Questions

**Q1: Subjectivity Acceptance**
The framework explicitly embraces that grading cannot be objective. Do you agree with this philosophical stance?

- **If yes:** How do we convince stakeholders (students, administrators) that "consistent subjectivity" is acceptable?
- **If no:** What aspects of grading do you consider objective, and how should they be formalized?

**Q2: LLM-Extracted QDs vs. Instructor-Specified Criteria**
The framework proposes that QDs should be extracted by LLM from student corpus, rather than specified by instructor.

- Does this align with pedagogical goals?
- Should instructors have veto power over QD sets?
- Hybrid approach: instructor seeds initial QDs, LLM refines?

**Q3: Concept-Fidelity as Primitive**
The framework uses "concept-fidelity" (reflects intended meaning) without defining it precisely.

- Is this acceptable as a primitive construct?
- Or do we need to decompose it into measurable components?
- How would you define "intended meaning" operationally?

**Q4: Holistic vs. Decomposed Grading**
We clarified that the framework evaluates texts holistically across QD space, not as sum of per-dimension scores.

- Does this match how expert graders actually think?
- Or do graders decompose into criteria then aggregate?
- Can LLMs perform holistic evaluation reliably?

**Q5: Coupling Implications**
If energy and charge QDs are irreducibly coupled for voltage, should they be merged?

- Does merging lose pedagogical value? (e.g., we want to know if student understands energy specifically)
- Or does merging better reflect how the concept should be understood?
- Are there cases where coupled concepts should still be evaluated separately?

### Practical Implementation Questions

**Q6: Necessary QD Definition**
Who defines which QDs are necessary for each question?

- **Option A:** Instructor specifies upfront (more control, more work)
- **Option B:** LLM infers from reference solutions (less work, less control)
- **Option C:** Instructor validates LLM-proposed necessary QDs (balanced)

**Q7: Error Propagation Weighting**
Should foundational errors be penalized more heavily than propagated errors?

- Example: "CPUs in steam" (wrong) → "use CPU from steam" (propagated)
- **Strict view:** Both wrong, equal penalty
- **Nuanced view:** Second error follows from first, less culpable
- Which aligns with your grading philosophy?

**Q8: Adversarial Content Handling**
When student adds "this deserves full marks" to their answer:

- **Option A:** Ignore completely (filtering approach)
- **Option B:** Flag and penalize (integrity violation)
- **Option C:** Flag for manual review
- What should the default policy be?

**Q9: Feedback Granularity**
What level of detail should automated feedback provide?

- **Minimal:** "Your answer is between acceptable and excellent" (current framework)
- **Detailed:** "Compared to excellent, you're missing [specific QD]. See example X."
- **Very detailed:** "Your energy-charge relationship is correct, but you could improve precision by..."

**Q10: Gradual Rollout Strategy**
How should this system be deployed in practice?

- **Pilot:** Low-stakes formative assessments only
- **Assisted:** System suggests grades, instructor reviews/adjusts
- **Autonomous:** System grades, instructor spot-checks
- **Trusted:** System grades independently after validation
- What's the right progression?

### Validation and Trust Questions

**Q11: Validation Threshold**
What correlation with instructor grades is "good enough" for deployment?

- **Conservative:** ρ > 0.90 (matches inter-human agreement)
- **Pragmatic:** ρ > 0.80 (better than many TA graders)
- **Permissive:** ρ > 0.70 (useful for feedback, requires oversight)

**Q12: Consistency vs. Correctness Priority**
If forced to choose, which matters more:

- **Consistency:** Same answer always gets same grade (ρ could be lower)
- **Correctness:** Grades match instructor intent (κ could be lower)
- **Both equally:** Need high marks on both metrics

**Q13: Failure Mode Tolerance**
What types of errors are acceptable vs. unacceptable?

- **Acceptable:** Borderline cases graded differently than instructor
- **Maybe acceptable:** Giving partial credit when instructor gives zero (or vice versa)
- **Unacceptable:** Marking clearly correct answer as wrong
- **Unacceptable:** Being fooled by adversarial attacks
- Where do you draw the line?

**Q14: Explainability Requirements**
What do students need to understand about how they were graded?

- **Minimal:** "Here's your grade and general feedback"
- **Comparative:** "Here's how your answer compares to excellent/acceptable examples"
- **Analytical:** "Here's your QD profile and which dimensions need improvement"
- **Full transparency:** "Here's the complete QD set, equivalence class structure, and betweenness evaluation"

**Q15: Equity Considerations**
Does this framework advantage/disadvantage any student groups?

- Students with weaker writing skills but correct understanding?
- Students from non-native English backgrounds?
- Students who think differently (unconventional but correct approaches)?
- How do we ensure fairness across diverse populations?

### Extension and Future Direction Questions

**Q16: Multi-Criteria Grading**
Many assessments evaluate multiple dimensions:

- Correctness (factual accuracy)
- Clarity (communication quality)
- Creativity (novel applications)

Should the framework handle these separately or together?

- **Separate:** Different QD sets per criterion, weighted combination

- **Hybrid:** Some criteria separate (correctness), others holistic (overall quality)

- **Applied:** Engineering, business cases (multiple valid approaches)

Or does it need domain-specific adaptation?

**Q19: Scalability Limits**

What are the computational and conceptual bottlenecks?

## Part 6: Open Questions and Assumptions

### Assumptions Requiring Validation

**Assumption 1: LLM Consistency**

> There exists an LLM that can consistently evaluate concept-fidelity within equivalence classes.
> 

**Status:** Partially validated in literature (MTBench shows 80%+ agreement), but:

- Not validated for concept-fidelity specifically (only for general quality)
- Not validated for all domains (most tests on conversational tasks, not technical education)
- Not validated across multiple trials (test-retest reliability unclear)

**What we might need:** Measure Cohen's κ across repeated gradings of same corpus by same LLM. Target: κ > 0.85.

**Assumption 2: QD Adequacy**

> LLM-extracted quality dimensions capture sufficient variation to enable pedagogically meaningful rankings.
> 

**Status:** Untested.

**What we need:**

- Correlation between QD-induced rankings and instructor rankings (target: ρ > 0.80)
- Validation that QD set is complete (covers all pedagogically important aspects)
- Test whether QD set is minimal (no redundant dimensions)

**Assumption 3: Concept-Fidelity Reflects Intent**

> LLM's judgment of "reflects full intended meaning" aligns with instructor's judgment.
> 

**Status:** Untested and vaguely defined.

**What we need:**

- Operational definition of concept-fidelity
- Direct comparison: LLM rankings vs. instructor rankings
- Validation across domains (physics, CS, math, humanities)

**Assumption 4: Betweenness Preserves Ordering**

> New texts positioned via betweenness receive grades consistent with their position in concept-fidelity ordering.
> 

**Status:** Theoretically sound (betweenness is a standard geometric operation), but:

- Not validated in educational context
- Not tested with compound QDs
- Not tested under adversarial conditions

**What we need:**

- Validate that B(a,b,c) judgments are consistent across repeated trials
- Test whether students positioned "between" two examples actually perform between those levels

**Assumption 5: Holistic Evaluation Works**

> LLM can evaluate texts holistically across QD space without per-dimension decomposition.
> 

**Status:** Based on our interpretation, not explicit in framework.

**What we need:**

- Test prompts: "holistic ranking" vs. "per-dimension scoring then aggregate"
- Compare accuracy and consistency
- Validate with instructor preferences

### Open Research Questions

**Q1: Optimal Number of QDs**
How many quality dimensions should be extracted?

- Too few → miss important variation
- Too many → over-fitting, redundancy, computational cost

**Current guidance:** 2-3 iterations typically sufficient, but no principled stopping criterion.

**Proposed investigation:**

- Extract QDs with varying iteration counts (1, 2, 3, 4, 5)
- Measure: accuracy, interpretability, redundancy
- Find knee of curve (diminishing returns)

**Q2: Cross-Assessment Generalization**
Do QDs transfer across related assessments, or must they be re-extracted every time?

**Example:**

- Assessment 1: "What is voltage?"
- Assessment 2: "Explain voltage in a circuit"
- Can we reuse {energy-per-charge, potential-difference} QDs?

**Hypothesis:** Some QDs transfer (domain concepts), others don't (assessment-specific requirements).

**Q3: Hierarchical QDs**
Should QDs have hierarchical structure?

- High-level: "understanding of voltage concept"
    - Mid-level: "energy-per-charge relationship"
        - Low-level: "mentions energy", "mentions charge", "ratio structure"

**Advantage:** Captures different levels of abstraction
**Challenge:** How to map texts to hierarchy? Which level for equivalence classes?

**Q4: Temporal Dynamics**
If we collect student work over multiple years, can we refine QDs based on accumulated data?

**Adaptive QD refinement:**

- Year 1: Extract initial QDs
- Year 2: Analyze new corpus, adjust QDs
- Year 3: Further refinement
- Converge to stable, well-validated QD set

**Q5: Multi-Dimensional Rubrics**
Some assessments evaluate multiple orthogonal skills:

- Correctness (factual accuracy)
- Clarity (communication)
- Creativity (novel applications)

**Current framework:** Only addresses correctness.

**Extension needed:** How to apply framework to multi-criteria grading?

**Proposed approach:**

- Extract separate QD sets for each criterion
- Build separate equivalence classes per criterion
- Final grade = weighted combination

**Q6: Numerical Score Assignment**
Framework provides rankings, but instructors need numerical scores.

**Current gap:** Betweenness tells us b is "between a and c" but not WHERE between.

- Is b at 75% (closer to a) or 55% (closer to c)?

**Proposed solutions:**

- **Equal spacing:** If k reference texts, divide range into k+1 equal intervals
- **Density-based:** Use concept-fidelity "distance" between texts
- **Calibration:** Map rankings to scores using validation set

**Q7: Feedback Generation**
How to generate actionable feedback from betweenness comparisons?

**Current approach:** "Your answer is between these examples."

**Better approach:** "Compared to excellent example, you're missing [specific dimension/detail]. To improve, [specific suggestion based on reference text]."

**Challenge:** Extract **what differs** between student text and higher-reference text, beyond "concept-fidelity is lower."

**Q8: Handling Unanticipated Answers**
What if a student gives a correct answer using QDs not in the extracted set?

**Example:**

- Extracted QDs: {energy-per-charge, potential-difference}
- Student: "Voltage is the line integral of electric field"
- QD profile: {calculus, field theory} ← **not in extracted QDs**

**Options:**

- Manually add QDs (doesn't scale)
- Recognize as correct despite not matching extracted structure
- Flag for instructor review

**Proposed:** Hybrid approach with "escape hatch" for unanticipated correct answers.
