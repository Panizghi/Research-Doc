## Part 8: Summary of Key Concepts for Quick Reference

### Core Framework Components

| Component | Definition | Purpose |
| --- | --- | --- |
| **Quality Dimension (QD)** | Binary feature (present/absent) extracted by LLM from corpus | Capture variation in student responses |
| **Equivalence Class** | Set of texts with identical QD profile | Group structurally similar texts |
| **Partial Ordering** | ⊂ relation on equivalence classes by QD set inclusion | Organize texts by structural completeness |
| **Concept-Fidelity** | LLM's judgment of how well text reflects intended meaning | Rank texts within equivalence class |
| **Total Ordering** | Sequence of texts from high to low concept-fidelity | Rank all texts in a class |
| **Betweenness** | B(a,b,c) = true if b's quality is between a and c | Position new texts in existing ranking |
| **Necessary QD** | Dimension that must be present in correct answers | Filter what matters for grading |
| **Sufficient Class** | Class where correct answers are possible | Identify complete answer structures |
| **Compound QD** | Multiple atomic QDs evaluated together | Handle irreducible coupling |

### Key Problems

| Problem | Description | Proposed Solution |
| --- | --- | --- |
| **Orthogonality Crisis** | QDs aren't independent; often irreducibly coupled | Compound QDs, coupling detection, merger algorithm |
| **Structure ≠ Correctness** | Having all QDs doesn't guarantee correct statements | Three-level evaluation: structural + semantic + concept |
| **Mixtures** | Answers mix correct and incorrect statements | Error propagation tracking, differentiated penalties |
| **Concept-Fidelity Undefined** | Core construct lacks operational definition | Proxy metrics, validation against expert judgments |

### Key Problems (Continued)

| Problem | Description | Proposed Solution |
| --- | --- | --- |
| **Adversarial Vulnerability** | Students can inject flattery, magic words to manipulate grades | Non-necessary QD filtering, adversarial dimension detection |
| **Error Propagation** | Errors in foundational claims contaminate downstream reasoning | Dependency graphs, weighted penalties (foundational > propagated) |
| **Holistic vs. Decomposed** | Unclear whether evaluation is per-dimension or aggregate | Clarify: holistic evaluation across QD space, not sum of parts |

### Key Extensions

| Extension | What It Adds | Impact |
| --- | --- | --- |
| **Compound QDs** | Groups coupled atomic QDs into single evaluable unit | Preserves semantic coherence, enables meaningful evaluation |
| **Non-Necessary Filtering** | Discards truth/falsity of non-necessary dimensions | Defends against adversarial attacks, handles irrelevant content |
| **Error Propagation Tracking** | Distinguishes foundational vs. propagated errors | Fairer grading, more informative feedback |
| **Fuzzy QD Presence** | Degree of structure (0-1) instead of binary | Captures sophistication levels, enables finer gradations |
| **Adversarial Detection** | Identifies and filters manipulative content | Robust grading resistant to prompt hacking |
| **Dependency Graphs** | Models which QDs build on which | Enables cascading correctness evaluation |
