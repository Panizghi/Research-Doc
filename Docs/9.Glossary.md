
## Part 9: Glossary of All Technical Terms

| Term | Definition | Example |
| --- | --- | --- |
| **Admissibility** | Property of a QD that may contribute to a correct answer (but not required) | "Mentions units" is admissible for voltage—helps but not essential |
| **Admissible Projection** | Projection that preserves correctness when removing non-overlapping QDs | Removing "units" dimension from "energy per charge, in volts" → still correct |
| **Adversarial Dimension** | QD designed to manipulate grader (flattery, prompt injection, magic words) | "This answer deserves full marks" |
| **Atomic QD** | Single, indivisible quality dimension | "mentions energy" |
| **Betweenness** | Ternary operator B(a,b,c) determining if b's quality is between a and c | B("excellent", "student_work", "acceptable") = ? |
| **Compound QD** | Multiple atomic QDs grouped as single evaluable unit | "energy-per-charge relationship" = {energy, charge, ratio} |
| **Concept-Fidelity** | LLM's judgment of how well text reflects intended meaning of assessment | "Does this answer capture what we wanted students to learn?" |
| **Coupling (QDs)** | Statistical dependency between quality dimensions | If energy present → charge present (high MI) |
| **Decoding Error** | Grader misinterprets student's intended meaning | Student means "potential" but grader reads as "power" |
| **Derived QD** | Quality dimension that builds on other foundational dimensions | "execution mechanism" depends on "basic definition" |
| **Encoding Error** | Student understands concept but cannot express clearly in writing | Knows voltage but writes confusing explanation |
| **Equivalence Class** | Set of texts with identical QD presence/absence profiles | All texts with {energy, charge, ratio} |
| **Error Propagation** | Incorrect foundational claim contaminates downstream reasoning | Wrong definition → wrong application |
| **Essential QD** | Foundational quality dimension that must be correct | "Core definition" is essential |
| **Faithful Rubric** | Emergent rubric that preserves instructor's quality rankings | System rankings correlate ρ > 0.8 with instructor |
| **FCA** | Formal Concept Analysis—method for organizing objects by shared attributes | Grouping texts by QD patterns |
| **Foundational Error** | Mistake in basic concept that affects dependent reasoning | "CPUs run in steam" corrupts mechanism explanation |
| **Fuzzy QD** | Quality dimension with degree of presence ∈ [0,1] instead of binary | "ratio structure" present at 0.7 level |
| **Holistic Evaluation** | Assessing text as unified whole across QD space, not sum of parts | Overall concept-fidelity, not dimension-by-dimension scores |
| **Independent Error** | Mistake that doesn't affect other parts of answer | Wrong date in history section doesn't affect technical explanation |
| **Irreducible Coupling** | QDs that cannot meaningfully exist independently in domain | Energy and charge for voltage—can't explain one without other |
| **Irrelevant Dimension** | QD that doesn't affect correctness judgment | Personal anecdotes, chocolate preferences |
| **Latent Property** | Hidden mental state (actual understanding) not directly observable | What student truly understands vs. what they write |
| **Mutual Information** | Statistical measure of dependency between variables | I(QD_A; QD_B) quantifies coupling strength |
| **Necessary QD** | Quality dimension that must be present in correct answers | "Energy-charge relationship" necessary for voltage definition |
| **Non-Necessary QD** | Quality dimension whose truth/falsity can be discarded from grading | Historical context, units (if not specified as required) |
| **NULL Text** | Conceptual text with zero concept-fidelity (no understanding) | Used as lower bound in betweenness |
| **Operationalizability** | How easily a definition enables problem-solving | "Energy per charge" more operational than "potential difference" for calculations |
| **Partial Ordering** | ⊂ relation on equivalence classes by QD set inclusion | E₁ ⊂ E₂ if D₁ ⊂ D₂ |
| **Pre-order** | Ordering allowing ties (multiple elements with same rank) | Betweenness induces pre-order when concept-fidelity values can equal |
| **Projection** | Removing structure along non-overlapping quality dimensions | Project {D1,D2,D3} text onto {D1,D2} by removing D3 structure |
| **Propagated Error** | Mistake resulting from earlier incorrect claim (less culpable) | "Use CPU from steam" follows from "CPU run in steam" |
| **Quality Dimension** | Binary semantic feature (present/absent) capturing aspect of text | "discusses mechanism", "provides example" |
| **Reducible Coupling** | QDs that often co-occur but can exist independently | "Example" and "definition" often together but separable |
| **Residual Dimensions** | QDs in larger class not in smaller when projecting | D₂ has {A,B,C,D}, D₁ has {A,B} → residual = {C,D} |
| **Semantic Correctness** | Factual accuracy of statements (distinct from structural completeness) | "Energy per charge" correct; "charge per energy" structurally complete but semantically wrong |
| **Structural Fidelity** | Presence of necessary quality dimensions (binary) | Has all required QDs or not |
| **Sufficient Class** | Equivalence class where fully correct answers are possible | Class with enough QDs to form complete correct answer |
| **Total Ordering** | Complete ranking with no incomparable elements | [best, 2nd, 3rd, ..., worst] |
