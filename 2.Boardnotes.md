## Part 2: Problems Identified (From Boards and Discussion)

### 2.1 The Orthogonality Crisis (Board 3)

**Problem Statement:**
The framework treats QDs as independent binary features, but in reality, many QDs are **irreducibly coupled**—they cannot exist independently in pedagogically meaningful ways.

**Board Questions:**

1. "Under what conditions can we detect/quantify orthogonality?"
2. "W/o orthogonality, can we orthogonalize by revisiting the QDs? (probably via QI) merging, maybe image/split/Add/drop"
3. "Define orthogonality better"
4. "Can we id orthogonal subsets of QDs?"
5. "If you have irreducible coupling, how does betweenness lead to out rubric Discovery?"
6. "(Mike's ques: coupled QDs are actually not distinct)"

**Concrete Example:**

- **Question:** "What is voltage?"
- **QD_A**: "mentions energy"
- **QD_B**: "mentions charge"

**Problem:** Can a student meaningfully explain voltage with energy but not charge, or charge but not energy?

**Corpus Analysis:**

- Pattern 1: {A=1, B=0} (energy only) → **very rare** in good answers
- Pattern 2: {A=0, B=1} (charge only) → **very rare** in good answers
- Pattern 3: {A=1, B=1} (both) → **dominant** in correct answers
- Pattern 4: {A=0, B=0} (neither) → common in wrong/incomplete answers

**Interpretation:** Energy and charge are **irreducibly coupled** for voltage—good explanations need both. They should be merged into compound QD: "energy-per-charge relationship structure."

**Why This Matters:**
If QDs aren't independent:

- Equivalence class structure breaks down (texts with identical QD presence but different coupling patterns might be inappropriately grouped)
- Partial ordering doesn't capture quality relationships correctly
- Per-dimension correctness evaluation becomes incoherent (how do you evaluate "charge dimension" correctness when charge can't be discussed without energy?)

**Proposed Solution: Compound Quality Dimensions**

**Simple QD (current framework):**

```
d : Text → {0, 1}

```

**Compound QD (proposed):**

```
D : Text → P({d₁, d₂, ..., dₖ}) × {correct, incorrect}

```

where P is powerset of atomic dimensions

**Example:**
Instead of:

- QD_energy: present/absent
- QD_charge: present/absent
- QD_ratio: present/absent

Use:

- QD_voltage_definition: compound {energy, charge, ratio} → correct/incorrect

**Evaluation:** Check if the energy-charge-ratio relationship as a whole is correctly expressed, rather than evaluating each dimension separately.

### 2.2 Structure vs. Correctness Gap (Board 1)

**Problem Statement:**
Having complete structural coverage (all necessary QDs present) does not guarantee semantic correctness.

**Board 1 Diagram:**

```
[Min Acceptable] ←→ [QD structure can be anywhere] ←→ [Max Possible]
                              ↓
                        Actual quality

```

**The gap:** A text can have perfect structure but be wrong, or incomplete structure but be correct.

**Example 1: Perfect Structure, Wrong Semantics**

- **Question:** "What is voltage?"
- **Text:** "Voltage is charge per unit energy"
- **QD presence:** {energy ✓, charge ✓, ratio ✓} → **100% structural completeness**
- **Semantic correctness:** **WRONG** (backwards—should be energy per charge)

**Example 2: Incomplete Structure, Correct Semantics**

- **Text:** "Voltage is potential difference"
- **QD presence:** {potential ✓, difference ✓} → **different QD set, incomplete by original rubric**
- **Semantic correctness:** **CORRECT** (valid alternative definition)
From page 5: "The partial ordering does not on its own imply anything about correctness."
From page 6: "A text may have structure along all necessary quality dimensions but still be wrong."

**What's Missing:**

- How to evaluate per-dimension correctness when dimensions are coupled
- How to weigh correctness vs. completeness
- How to handle texts that are structurally complete but semantically wrong

**Proposed Solution: Three-Level Decomposition**

**Level 1: Structural Fidelity**

- Does text have structure in necessary QDs? (Binary: yes/no)

**Level 2: Semantic Correctness**

- Are statements along those QDs factually correct? (Binary: yes/no per QD, aggregated)

**Level 3: Concept Fidelity**

- How well does it capture intended meaning? (Continuous: 0-1 scale)

**Grading Formula:**

```
Final_Grade = f(structural_fidelity, semantic_correctness, concept_fidelity)

Example weighting:
  Final = 0.3 × structural + 0.5 × semantic + 0.2 × concept

```

**Example Application:**

- **"Charge per unit energy"**:
    - Structural: 100% (all QDs present)
    - Semantic: 0% (relationship backwards)
    - Concept: 0% (doesn't reflect intended meaning)
    - Final: 0.3 × 1 + 0.5 × 0 + 0.2 × 0 = 30%

### 2.3 The Mixtures Problem (Board 2)

**Problem Statement:**
Real student answers contain mixtures of correct and incorrect statements across and within dimensions. Framework acknowledges this but provides no formal handling.

**Board 2 Taxonomy:**

**① QDs are orthogonal and no incorrect statements**

- All QDs present and all statements correct
- **Example:** "CPUs are in computers. They execute instructions using transistors."
- **Grade:** 100%

**② QI, orth. and possibly incorrect statements**

- Orthogonal QDs with some incorrect statements
- **Sub-case 2a: Totally correct + incorrect mixtures (independent errors)**
    - **Example:** "CPUs are in computers. They execute instructions. They were invented in 1850."
    - Wrong date, but doesn't affect CPU understanding
    - **Grade:** 80% (isolated error)
- **Sub-case 2b: Dependent errors with propagation**
    - **Example:** "CPUs are in computers. CPU run in steam. Computer use CPU from steam to be run."
    - Foundational claim ("in computers"): CORRECT
    - Derived claim ("run in steam"): INCORRECT
    - Subsequent reasoning: CONTAMINATED by error
    - **Grade:** 40-50% (foundational ok, mechanism wrong)

**③ QD coupling + "Corrupted da not electricity"**

- Coupled dimensions where error in one corrupts understanding of the other
- **Example:** "Voltage is power per amp"
    - Energy QD: present but used wrong
    - Charge QD: absent (should be "charge" not "current")
    - Ratio QD: present
    - Coupling makes it hard to separate which dimension is wrong
- **Grade:** 30% (structure present, relationship fundamentally wrong)

**④ Single QD or mult QD**

- Unclear from board—possibly referring to whether error affects one dimension or propagates to multiple

**Framework's Current Handling (Page 7):**

> "Texts may be partially correct with errors if they contain a mixture of correct and incorrect statements. The exact distinction is left to the instructor."
> 

**What's Missing:**

- Distinguishing independent vs. propagated errors
- Weighting foundational vs. derived correctness
- Tracking error propagation through reasoning chains

### 2.4 Error Propagation in Reasoning Chains

**Problem Statement:**
Student answers often contain reasoning chains where later statements build on earlier ones. Errors in foundational claims contaminate downstream reasoning.

**Example (Detailed Analysis):**

**Statement Chain:**

1. "CPUs are in computers" → **CORRECT** (foundational)
2. "CPU run in steam" → **INCORRECT** (bizarre claim, builds on CPU concept)
3. "Computer use CPU from steam to be run" → **INCORRECT** (propagated from statement 2)

**Quality Dimension Profile:**

- QD_A (CPU-computer relationship): **PRESENT** → Statement 1 ✓
- QD_B (processing mechanism): **PRESENT** → Statement 2 ✗
- QD_C (operational description): **PRESENT** → Statement 3 ✗

**Current Framework Evaluation:**

- All QDs present → 100% structural completeness
- But 2/3 statements wrong → How to score?

**What's Needed: Error Type Classification**

**Type A: Independent Errors**

- Incorrect statements that don't affect other statements
- **Example:** "CPUs are in computers. The sky is green. CPUs process data."
- Middle statement wrong but isolated
- **Score impact:** -ve points for error, other statements unaffected

**Type B: Foundational Errors**

- Incorrect statements that subsequent reasoning depends on
- **Example:** "CPU run in steam" (statement 2)
- Statement 3 builds on this error
- **Score impact:** -ve points (contaminates downstream)

**Type C: Propagated Errors**

- Incorrect statements that result from earlier errors
- **Example:** "Computer use CPU from steam to be run" (statement 3)
- Wrong BECAUSE statement 2 was wrong
- **Score impact:** -ve points (less culpable, follows from earlier mistake)

**Sample Scoring with Error Propagation:**

```
Statement 1 (foundational, correct): +50 points
Statement 2 (foundational, incorrect): -30 points
Statement 3 (propagated, incorrect): -10 points

Total: 50 - 30 - 10 = 10 points / 50 possible = 20%

```

**Alternative interpretation if Steam considered non-necessary:**

```
If "software platforms" is non-necessary QD:
  Project onto necessary QDs: {CPU-computer, processing}
  Statement 1: correct ✓
  Statement 2: "CPU run" (removing "in steam") → incomplete but not wrong
  Grade: 60%

```

**This connects to the non-necessary QD filtering principle discussed later.**

### 2.5 Concept-Fidelity Is Undefined

**Problem Statement:**
Concept-fidelity is the core construct for total ordering within equivalence classes, but it lacks operational definition.

**Framework's Definition (Page 9):**

> "A text has high concept-Fidelity whenever it is: (1) Correct, (2) Reflects the full intended meaning of the assessment"
> 

**The vagueness:**

> "The 'intended meaning' is an emergent property of a text that depends on the intersection of the expectations placed on the students, the personal beliefs of the instructor, and the judgment capabilities of the grader."
> 

**What This Means:**

- Concept-fidelity = "you know it when you see it"
- Depends on LLM's judgment
- Assumes LLM can consistently rank texts, but no formal definition

## Side notes

**Literature Review Finding:**
No existing metrics in educational or NLP literature map to "concept fidelity." Related work uses:

- Knowledge Integration rubrics
- Semantic similarity (cosine distance)
- Feature-based scoring (SHAP, NAMs)
- Multi-dimensional rubrics

But none capture "reflects full intended meaning" holistically.

**PhysICO Benchmark Challenge:**
PhysICO distinguishes:

- **Surface understanding**: Keyword recognition (LLMs 95%+ accurate)
- **Deep understanding**: Abstract reasoning (LLMs only 41-52% vs. 90%+ human)

**Question:** Does concept-fidelity capture deep understanding or just surface matching?

**What's Needed:**

- Operational definition of concept-fidelity
- Validation that LLM rankings correlate with expert rankings
- Test whether concept-fidelity distinguishes memorization from genuine understanding

**Proposed Approach:**

```
Concept_Fidelity(text, equivalence_class) = weighted_average(
    correctness_score,         # all QDs correct?
    completeness_score,        # all necessary QDs present?
    precision_score,           # uses precise terminology?
    coherence_score,           # logically coherent?
    depth_score                # shows deep vs. surface understanding?
)

```

But this still requires defining each component metric.

### 2.6 Holistic vs. Decomposed Evaluation (Clarification from Discussion)

**Critical Insight:**
The framework evaluates texts **holistically across QD space**, not as sum of per-dimension scores. This was ambiguous until our discussion.

**What Framework Actually Does:**

- Betweenness compares overall concept-fidelity within equivalence class
- Evaluation is holistic: "How good is this text overall?"
- Not decomposable into per-dimension scores

**Why This Matters:Holistic evaluation naturally handles coupling:**

- Don't need dimensions to be independent
- Coupled dimensions contribute to holistic judgment together
- Example: "energy-per-charge" evaluated as unified concept, not energy + charge + ratio separately

**LLM Prompt Implications:**

```
WRONG APPROACH:
"Rate this text on each dimension:
 - Energy dimension: 8/10
 - Charge dimension: 7/10
 - Ratio dimension: 9/10
 Total: 8 + 7 + 9 = 24/30"

CORRECT APPROACH:
"Considering all quality dimensions together as a complete
picture of concept understanding, rank these three texts
by overall concept-fidelity: [a, b, c]"

```

**Consequence for orthogonality problem:**

- QDs don't need to be statistically independent
- They need to be **distinguishable features** LLM can detect
- Betweenness operates on holistic quality, so coupling is acceptable

**But:** This makes per-dimension correctness evaluation problematic. If we can't decompose, how do we evaluate "correct statements for every quality dimension"? This tension remains unresolved.
